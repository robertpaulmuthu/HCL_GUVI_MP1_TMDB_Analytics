# 🎬 TMDB Movie Analytics

## Project Overview

The TMDB Movie Analytics project is an end-to-end data analytics project that explores movie-related data to identify trends, patterns, and meaningful business insights.

The project uses six CSV datasets — Movies, Genres, Movie Genres, Cast, Crew, and Movie Keywords — to perform data cleaning, SQL-based data extraction, Exploratory Data Analysis (EDA), and data visualization.

## Tools & Technologies
- Python
- Pandas & NumPy
- SQL
- Matplotlib & Seaborn
- Streamlit
- Google Colab

## Project Workflow
1. Data Import
2. Data Cleaning & Preprocessing
3. SQL Data Extraction
4. Exploratory Data Analysis
5. Data Visualization
6. Insights & Findings
7. Interactive Dashboard using Streamlit

## Project Objectives
- Analyze movie budgets and revenues.
- Identify popular movie genres.
- Explore relationships between budget, revenue, and popularity.
- Analyze cast and crew information.
- Discover trends and patterns in the movie industry.
- Present insights through an interactive dashboard.
